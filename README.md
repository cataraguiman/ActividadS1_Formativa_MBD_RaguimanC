# ActividadS1_Formativa_MBD_RaguimanC
Actividad Formativa Semana 1.

Asignatura: Modelamiento de Bases de Datos: requerimiento de BT&Airways.

El presente archivo corresponde una actividad realizada a partir de los requerimientos solicitados por la línea aérea BT&Airways, utilizando la herramienta Oracle SQL Developer Data Modeler. El trabajo consistió en analizar el contexto de la empresa, identificar las principales entidades y sus respectivos atributos, determinar sus atributos identificadores y definir los tipos de datos (dominios) según corresponda. Una vez identificadas, se representó la información mediante modelos las cuales puedes ser visualizadas en doss: 1) Modelo Entidad-Relación (MER) en notación Barker y 2) Modelo en notación Bachman o Ingeniería de la Información).
